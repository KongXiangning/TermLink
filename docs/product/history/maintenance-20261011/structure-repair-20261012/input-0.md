## 2. 本轮解决的实际问题

本轮不是使所有节点都连起来，而是使用户已经采用、且材料有依据的业务结构可靠地保存为消费者可识别的结构，同时如实保留候选、未决和历史。

固定基线的真实问题链条为：用户要求按层级整理；TermLink 的维护解释将其收窄为分类导航；分类主要进入 extensions 和正文，正式关系未同步形成；部分关系因没有用户亲口指定内部 ID 被保留为 inferred；正文中的功能编号又不等于可独立管理的子需求；TraceLens 正式图按契约过滤这些关系，但没有在主要入口充分解释未连入原因。现有 v3 类型和关系已经能承载所需结构，并非缺少 Feature 系统。

## 3. 共同采用的规则

**业务范围与结构。** 当前总体要求来自原始已确认需求，经后续有效决定更新。Task 说明具体实施范围和结果，不能反向成为一个产品需求存在的必要条件。正常规划完整分析当前交付范围及重要质量要求，不默认只细化近期 Task。

**节点选择。** 有业务范围、需要核对达成情况的上层能力使用父 requirement；具体功能或质量要求使用子 requirement。纯分类可使用 module，平台或原文编号也可仅作为标签。module 不是 mandatory layer，也不作为交付评估对象。不得为图形结构新增业务承诺、指标或设备矩阵。

**关系采用。** declared 表示当前规范明确记录、有可追溯依据的关系，不要求用户说出内部 ID 或逐边签字。已有正式材料明确表达、用户已采用的层级，或授权明确涵盖的既有范围归类，可按实际依据记录；广义整理授权不自动采纳 AI 新推导的全部关系。无足够依据时保留 inferred 或未决，不批量转正，也不永久将所有 Agent 产出都视为 inferred。

**核心结构。** 已采用、需要被主图使用的结构通过稳定条目与 links 保存。extensions 和正文可补充来源、分类解释或简单细节，但不能在声称结构已交付时用它们替代核心关系。

**连续维护。** 新增、细化、变更或重新归类时，同一授权维护过程处理受影响定义、关系、顺序及依据，回读是否确实生效。“同次”不要求跨文件原子事务；部分失败保留成功结果，仅补失败部分。

**Task 软关联。** 无 PRODUCT、维护暂停、关联为空、功能未细化、结论未知或文档写失败，都不单独阻塞 Task。paused 与 closed 分别展示，closed 不被解释为全部工作完成，也不因业务缺口被重新打开。无新增需求审批、完整性认证、Task 门禁或后台监听服务。

**顺序。** 继续使用项目 requirement_order：已有相对顺序保留，新增身份按本批采用顺序追加。父子展开是视图组织，不为把子项挪到父项旁边重排数组。依赖、Task 活动和结果均不自动改序。

**达成与读取。** 沿用现有范围化 assessment、独立报告及其目标/范围/对象选择。无报告是未知，不是失败；关系成立不证明完成；不自动汇总百分比或子项全绿。TraceLens 读取规范文档，Task/Step 沿用已有 Runtime 只读查询及快照降级，不提供业务写回。

## 4. 三份方案的分工和实施次序

## 5. 统一交接材料

复用一套有限材料，分别保留“整理前真实状态”“整理后实际保存状态”和“隔离副本的新增场景”。交接注明仓库提交、安装资产依据、源文件和实际回读范围。候选包名或软件版本相同，不能替代实际资产核对。

报告按三个层次分开：结构/读取的确定性结果、宿主在给定材料上的实际维护行为、实际页面及只读交互。不得用 Schema 通过替代业务分解质量，不得用宿主预写好的完美数据冒充 Agent 正确生成，也不得把有限合成场景称为真实产品业务验收。

## 7. 共同非目标

不修改 TermLink 业务代码；不重做 Task reducer 或 Runtime API；不新建 Feature 类型、强制 module 层、自动目标完成引擎或完整性分数；不把既有 213 条描述机械对象化；不迁移全部旧报告；不为本轮全量重跑业务测试；不增加第二套分类数据库或全局候选推理系统。

仓库已有与本轮无关的页面风格、性能、归档、旧记录漂移及其他缺陷，不顺带扩大处理。若实施发现独立的必要问题，单独报告范围与影响，不能悄悄加入验收承诺。

## 8. 一致性复核

此为成稿后的自行复核，不是第二个审查人员意见，也不是项目测试。复核重点：三个方案采用同一节点/关系语义；没有把 module 变成必经层；没有把 ID 未由用户填写当成推断理由；没有让分类完成冒充功能节点管理；保留完整当前规划和可选 Task 关联；同次维护不被解释为跨文件强原子事务；所有拟议演练区分真实与合成。

源文件中的“本轮只做导航”等历史解释保留为历史，不被当作新授权；真实旧用户限制继续有效。三方以本次实际采用的范围和来源开展实施，不为消除孤立节点而扩大产品承诺。
