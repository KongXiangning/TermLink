# Android 20 项实测判定

日期：2026-10-13。结论：按本次列出的验收场景，**10 项通过，10 项不通过**。不通过项已出现足以阻止验收的失败；其余未完成的子场景不视为通过。这里的“通过”仅覆盖本次设备、宿主和测试场景，不代表全部兼容性或发布验收。

## 环境及方法

- 代码：`4d586e0f2dab1fef9d2c273b770796b63a7d873d`，生产代码未修改。
- 真机：Huawei VOG-AL00，Android 10，序列号 MQS7N19402011743，Huawei WebView 114.0.5.302。
- 已用 JDK 21 重新构建并安装本轮 debug APK。SHA256：`F148028B15FA3A8DFFE63CA483BCDA5A1CE9764BBDE817E68A357598D25DFD6A`。
- 本仓库服务端运行在 3010；USB reverse 与实际 WLAN 地址分别测试。断网用手机 Wi-Fi 关闭／开启，LAN 会话不依赖 USB reverse。
- 当前 Rust collector 已重新构建，显式启用 analyzer 及 history range/snapshot flags；Codex IPC 宿主可用。
- 手机通过生产界面的实际控件、触屏、系统文件选择器、通知及系统语言设置操作。临时 instrumentation 只驱动 UI 和保存证据，没有预置业务存储或模拟宿主结果。

- 单次脚本显示 `OK` 只表示动作完成；本报告结合屏幕内容、真实宿主请求和终端输入字节判定。脚本失败也不直接等于产品失败。

## 架构核查（13）

已读取 `CONTRACTS.md` 的 IPC 核心、`DECISIONS.md` AD-004 与 rollout collector 架构。未修改任何冻结链路。

- follower / desired subscription / reconnect / owner tracker 的现有边界测试 **49/49 通过**，证据 `ipc-boundary-tests.tap`。这不能替代所有真机边界回归。

- 当前发现不足以授权改变 IPC 权威、follower 生命周期或 Rust 外部 source 边界。此次只判定，没有实施架构重构。
